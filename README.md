# Proyecto Lovepage

Esta página web es un detalle romántico creado para Karen Sofía Pérez López. Está pensada como un pequeño regalo digital lleno de cariño y sorpresa.

## Qué contiene el proyecto

- `index.html`
  - Página principal con un mensaje cálido y personal.
  - Incluye un botón que lleva a la sorpresa especial.
  - El botón `Enviar abrazo` fue removido según la última solicitud.

- `sorpresa.html`
  - Página sorpresa con un efecto visual de corazones y partículas.
  - Reproduce la canción localmente usando una ruta relativa correcta.
  - Añade controles de audio para que se pueda reproducir cuando el autoplay sea bloqueado.
  - Los puntitos del corazón titilan en tonos rosados para una apariencia romántica.

## Qué se corrigió

- Se arregló un error en `index.html` causado por un bloque `<script>` duplicado.
- Se eliminó el JavaScript roto que impedía la carga correcta de la página.
- Se actualizó `sorpresa.html` para usar la ruta relativa correcta del archivo MP3.
- Se agregó `controls` al elemento `<audio>` para mejorar la experiencia en navegadores que bloquean autoplay.
- Se mejoró el estilo de los puntos del corazón para que sean todos rosados y brillen.

## Dedicado a Karen

Este proyecto es un mensaje directo a Karen Sofía Pérez López, una chica muy especial que inspira amor y ternura. Cada detalle de la página está diseñado para transmitir ese afecto:

- Colores suaves y románticos.
- Animaciones de corazón.
- Música que acompaña la sorpresa.
- Un mensaje personal lleno de cariño.

## Cómo usarlo

1. Abre `index.html` en el navegador.
2. Desde allí, haz clic en el enlace para ir a la sorpresa.
3. En `sorpresa.html`, la canción intenta arrancar sola y también puedes usar el reproductor si es necesario.

## Notas

- El HTML y el CSS están diseñados para verse bien en móvil y escritorio.
- Si deseas, puedo añadir ahora una página adicional con un plano cartesiano y un corazón geométrico en `abrazo.html`.
